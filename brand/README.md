| File | What | Size |
|---|---|---|
| `avatar-a-wave.png` | Profile photo (main): a yellow square wave on navy | 1080 × 1080 |

Drawn on a 36 × 36 pixel grid and scaled 30× (nearest neighbour), in the Endesga 32 colours the videos use: navy `#181425`, yellow `#fee761`, shadow `#be4a2f`, cyan `#2ce8f5`. The mark fills about 60% of the circle so it still reads at the ~40 px size Instagram shows in feeds and comments.
